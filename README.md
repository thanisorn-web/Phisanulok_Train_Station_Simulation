# แบบจำลองสถานีรถไฟพิษณุโลก

แบบจำลอง 3 มิติการไหลของผู้โดยสารในสถานีรถไฟพิษณุโลก สร้างด้วย three.js

เปิดใช้งาน: https://thanisorn-web.github.io/Phisanulok_Train_Station_Simulation/

- ผังรางและอาคารประมาณจากภาพถ่ายดาวเทียม ระยะเป็นค่าโดยประมาณ
- เวลาถึง-ออกของ 22 ขบวนตามตารางเดินรถสถานีรถไฟพิษณุโลกของ รฟท. ส่วนชานชาลาและจำนวนผู้โดยสารเป็นค่าสมมติ
- ทั้งหมดอยู่ในไฟล์ `index.html` ไฟล์เดียว ไม่ต้อง build
